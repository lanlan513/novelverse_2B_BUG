# 逐段精读笔记（Close Reading Notes）

在经典小说选段上逐句精读、随手批注的阅读应用：选中原文句子，为**人物 / 叙事 / 语言 / 象征 / 情节**五个维度做笔记；笔记精确锚定在原文对应位置，可按章节、类型、关键词查找，并能在原文换版后自动重新定位。

## 功能

**批注与定位**
- 鼠标拖选或触屏选择句子，浮出「写精读笔记」气泡（快捷键 `N`）
- 五类笔记用五种颜色区分；正文批注位置显示编号角标，右侧面板同步列出
- 同一句上的**重叠笔记**以双色底纹标记，点击后弹出选择器逐条查看
- 批注可跨段落，诗句（《葬花吟》）按行正确渲染

**版本变化（核心难点）**
- 笔记从不保存字符偏移，只保存「引文 + 前后各 18 字上下文 + 段落提示」
- 每次渲染都经过重锚引擎：**精确命中 → 多处出现时按上下文消歧 → 编辑距离模糊匹配 → 悬挂**
- 切换《红楼梦》第三回的「程甲本 / 脂评本」即可看到：未改句子精确保留、一字异文模糊命中、整句改写悬挂在原段落并提供「放宽重新匹配」
- 顶部横幅汇总「X 条未找到 / Y 条近似匹配 / 全部吻合」

**查找**
- 章节（左侧目录）、类型（五类 + 全部，带计数）、关键词（同时搜引文与笔记内容，正文与列表高亮命中）
- 本章 / 全书两种范围；不匹配的批注在正文自动变淡
- `J / K`（或 `Alt+↑/↓`）在有笔记的句子间顺序跳转并滚动居中、脉冲高亮

**编辑、删除、恢复**
- 修改类型与内容；删除是软删除，进入**回收站**可一键恢复，也可永久删除
- 删除后立即出现「撤销」提示

**保存状态与异常处理**
- 顶栏保存指示器：已保存 / 保存中 / 保存失败（已暂存本机）/ 离线模式，显示待同步项数
- 乐观更新：先写本地（localStorage）再请求服务器；失败自动入队，6 秒后重试，恢复联网时批量补传
- 创建接口接受客户端生成的 id，重试幂等，不产生重复笔记
- 浏览器不支持 Selection API 时（或在受限环境中）自动切换为「点句批注」模式：每个句子成为按钮
- 所有浮层在窄屏（≤560px）退化为底部抽屉；侧栏与笔记面板在 ≤980px 变为抽屉式

**长文本与性能**
- 重锚结果与片段切分全部 `useMemo`，搜索按键不触发重算
- 片段按区间端点合并，500 条笔记只产生约 900 个渲染节点（见 `scripts/test-perf.mjs`）
- 段落组件 `memo`，三栏各自独立滚动，`overscroll-behavior: contain`

## 技术栈

React 18 + Vite + Express（数据持久化到 `data/store.json`），无其他运行时依赖。

| 文件 | 职责 |
| --- | --- |
| `src/reader/anchor.js` | 重锚引擎：归一化、精确/消歧/带状编辑距离模糊匹配、Selection→原文偏移 |
| `src/reader/segments.js` | 把笔记区间切成按段落、可重叠的渲染片段；兜底模式的句子切分 |
| `src/reader/store.js` | 笔记数据层：乐观更新、离线队列、回收站、播种 |
| `src/reader/texts.js` | 原文数据（《红楼梦》第 3 / 23 / 27 回）与两个版本的异文 |
| `src/reader/components/` | 阅读栏、笔记面板、浮层、编辑器、回收站 |
| `server.js` | `/api/notes` 增删改查（软删除、幂等创建、批量播种） |

## 运行

```bash
npm install
npm run dev        # API :8787 + Vite :5173（已配置代理）
# 或
npm start          # 仅 API + 构建产物（先 npm run build）
```

首次打开会自动播种 12 条示例笔记（清除服务端所有笔记后刷新会重新播种）。

## 测试

```bash
npm test
```

- `test:anchor` — 21 项：精确匹配、上下文消歧、版本异文模糊/悬挂、归一化、12 条引文往返（5ms）
- `test:dom` — 13 项（jsdom）：段内/跨段选区偏移、选区越界与 API 缺失、重叠与跨段片段、锚点往返
- `test:perf` — 500 条笔记：重锚 < 300ms、切分 < 100ms、渲染片段 < 4000
- `test:app` — 20 项（jsdom 加载生产构建 + 同进程 Express）：挂载、播种、类型/范围/关键词筛选、浮层、删除-恢复、版本切换、无运行时错误
